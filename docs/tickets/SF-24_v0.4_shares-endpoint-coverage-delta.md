# SF-24: Shares Endpoint Coverage Delta

**Module:** `sharefile-sdk-client`
**Depends on:** SF-11, SF-12
**Milestone:** v0.4 Endpoint Coverage
**Spec Reference:** [API_REFERENCE.md](../API_REFERENCE.md) &sect;5, [API_ENDPOINT_COVERAGE.md](../API_ENDPOINT_COVERAGE.md) Shares

## Goal

Add public `SharesClient` and transfer APIs for Shares endpoints that are missing after SF-11 and
SF-12.

## Requirements

1. Add recipient and item detail connectors:
   - `GET /sf/v3/Shares({shareId})/Recipients({recipientId})`
   - `POST /sf/v3/Shares({shareId})/Recipients`
   - `GET /sf/v3/Shares({shareId})/Items({itemId})`
   - `GET /sf/v3/Shares({shareId})/Items({itemId})/Thumbnail`
   - `GET /sf/v3/Shares({shareId})/Items({itemId})/ProtocolLinks({platform})`
2. Add recipient download connectors:
   - `GET /sf/v3/Shares({shareId})/Recipients({aliasId})/DownloadWithAlias`
   - `POST /sf/v3/Shares({shareId})/Recipients({aliasId})/BulkDownload`
3. Add alias and share email connectors:
   - `POST /sf/v3/Shares({id})/Alias`
   - `DELETE /sf/v3/Shares({id})/Alias?email={email}`
   - `POST /sf/v3/Shares/Send`
   - `POST /sf/v3/Shares/SendCallback`
   - `POST /sf/v3/Shares/Request`
   - `POST /sf/v3/Shares/Resend`
4. Add inbox and message connectors:
   - `GET /sf/v3/Shares({id})/Redirection`
   - `GET /sf/v3/Shares/Inbox`
   - `GET /sf/v3/Shares/Inbox({id})`
   - `GET /sf/v3/Shares({shareId})/Recipients({aliasId})/Message`
5. Keep `createSendShare` and `createRequestShare` against `POST /Shares` for backward
   compatibility; add separate exact connectors for `POST /Shares/Send` and `POST /Shares/Request`.

## Acceptance Criteria

- Mock transport tests assert exact HTTP method, path, and query parameters for each endpoint family.
- Existing SF-11 and SF-12 Shares behavior remains backward compatible.
- Download endpoints that return redirect specifications keep streaming storage-zone behavior out of
  resource clients unless implemented through `TransferClient`.
