# SF-22: Items Endpoint Coverage Delta

**Module:** `sharefile-sdk-client`
**Depends on:** SF-09, SF-12
**Milestone:** v0.4 Endpoint Coverage
**Spec Reference:** [API_REFERENCE.md](../API_REFERENCE.md) &sect;3, [API_ENDPOINT_COVERAGE.md](../API_ENDPOINT_COVERAGE.md) Items

## Goal

Add public `ItemsClient` and transfer APIs for Items endpoints that are missing after SF-09 and SF-12.

## Requirements

1. Add exact GET connectors:
   - `GET /sf/v3/Items`
   - `GET /sf/v3/ConnectorGroups({id})/Children`
   - `GET /sf/v3/Items({id})/WebView`
   - `GET /sf/v3/Items({id})/ProtocolLinks({platform})`
   - `GET /sf/v3/Items({id})/Redirection`
2. Add exact POST connectors:
   - `POST /sf/v3/Items({accountId})/SymbolicLink`
   - `POST /sf/v3/ConnectorGroups({id})/Children`
   - `POST /sf/v3/Items/AdvancedSimpleSearch`
   - `POST /sf/v3/Items/BulkDeletePermanently`
   - `POST /sf/v3/Items({id})/WebAppLink`
   - `POST /sf/v3/Items({id})/RemoveTemplateAssociation`
   - `POST /sf/v3/Items({id})/CheckVersioningViolation`
   - `POST /sf/v3/Items({parentId})/CheckIfPreviewable`
   - `POST /sf/v3/Items({folderId})/Upload`
3. Add exact PATCH connectors:
   - `PATCH /sf/v3/Items/Link({id})`
   - `PATCH /sf/v3/Items/Note({id})`
   - `PATCH /sf/v3/Items/SymbolicLink({id})`
4. Keep existing non-exact permanent delete behavior intact, but add a connector for the exact
   `BulkDeletePermanently` endpoint.
5. Keep existing `Upload2` transfer behavior intact; add the legacy `Upload` negotiation connector
   only where the API reference requires it.

## Acceptance Criteria

- Mock transport tests assert exact HTTP method and path for every added endpoint family.
- Existing Items and Transfer tests continue to pass.
- No existing public method is removed or silently remapped to a different endpoint.
