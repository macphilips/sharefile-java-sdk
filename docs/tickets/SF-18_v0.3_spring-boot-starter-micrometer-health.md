# SF-18: Spring Boot Starter -- Micrometer Metrics & Health

**Module:** `sharefile-spring-boot-starter`
**Depends on:** SF-17
**Milestone:** v0.3
**Spec Reference:** [TECH_SPEC.md](../TECH_SPEC.md) &sect;11.3 (Micrometer), &sect;14.3 (Health Indicator)

## Goal

Implement `MicrometerMetricsProvider` and `ShareFileHealthIndicator`.

## Requirements

1. **MicrometerMetricsProvider** per &sect;11.3 -- implements `MetricsProvider` using Micrometer `MeterRegistry`.

2. **ShareFileHealthIndicator** per &sect;14.3 -- Actuator health at `/actuator/health/sharefile`.

3. Distributed tracing support per &sect;14.4 (inherited via RestClient observation context).

## Acceptance Criteria

- `sharefile.http.requests` timer recorded in MeterRegistry
- Health returns UP with subdomain + token expiry
- Health returns DOWN with error on failure
