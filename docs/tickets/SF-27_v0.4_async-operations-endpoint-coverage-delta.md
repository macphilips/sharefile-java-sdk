# SF-27: AsyncOperations Endpoint Coverage Delta

**Module:** `sharefile-sdk-client`
**Depends on:** SF-10
**Milestone:** v0.4 Endpoint Coverage
**Spec Reference:** [API_REFERENCE.md](../API_REFERENCE.md) &sect;12, [API_ENDPOINT_COVERAGE.md](../API_ENDPOINT_COVERAGE.md) AsyncOperations

## Goal

Add the AsyncOperations endpoints documented in the API reference but missing after SF-10.

## Requirements

1. Add exact GET connectors:
   - `GET /sf/v3/AsyncOperations/GetByBatch({batchId})`
   - `GET /sf/v3/AsyncOperations/GetBatch({batchId})`
   - `GET /sf/v3/AsyncOperations/GetByFolder({folderId})`
2. Add exact mutation connectors:
   - `POST /sf/v3/AsyncOperations({id})/Cancel`
   - `POST /sf/v3/AsyncOperations/CancelBatch({batchId})`
   - `PATCH /sf/v3/AsyncOperations({id})`
   - `DELETE /sf/v3/AsyncOperations({id})`
3. Keep existing `list()` and `awaitCompletion()` behavior intact even though `GET /AsyncOperations`
   is not documented in `API_REFERENCE.md`.

## Acceptance Criteria

- Mock transport tests assert exact HTTP method and path for every added endpoint.
- Existing polling behavior continues to use `GET /AsyncOperations({id})`.
